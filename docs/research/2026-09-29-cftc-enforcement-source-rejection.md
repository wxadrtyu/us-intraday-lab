# CFTC enforcement-release source rejection

Decision: **ABANDON_CFTC_ENFORCEMENT_RELEASE_SOURCE**. The line is frozen during source design, before preregistration, complete index or pleading acquisition, respondent mapping, event-cube access, or any post-release return read. The frozen 2021-2023 event cube remains a **527-symbol coverage-limited sample, not the full US market**.

## Current pages do not establish historical first-publication state

CFTC enforcement press releases carry a release number and a displayed date and commonly say the Commission acted "today." Those fields identify the announcement, but the current site provides no immutable publication receipt, historical page snapshots, or version ledger proving which page and attachment bytes were public at that time. Current HTTP `Last-Modified` values are CDN/current-object metadata and cannot recover historical first-publication time.

The Commission's own [Release 7366-16](https://www.cftc.gov/PressRoom/PressReleases/7366-16) demonstrates that a numbered press release and its attached order can be edited after the displayed release date. The current page retains `May 9, 2016`, states that the release was edited for technical corrections and other adjustments to the attached order, and reports `Last Updated: July 20, 2016`. It exposes the revised current state, not the original page/order bytes or a timestamped version chain. Therefore a rule that treats the displayed release date or release number as proof of immutable first-publication content is not auditable. The same platform's current [2021 Coinbase release](https://www.cftc.gov/PressRoom/PressReleases/8369-21) retains its March 19 date but exposes neither a first-publication timestamp nor version history; today's HTTP metadata cannot supply either fact retroactively.

## Gross action volume does not cure the source defect

Official totals show 55 filed actions in FY2021, 82 enforcement actions in FY2022, and 96 in FY2023. The latter two are stated in [Release 8613-22](https://www.cftc.gov/PressRoom/PressReleases/8613-22) and [Release 8822-23](https://www.cftc.gov/PressRoom/PressReleases/8822-23); the FY2021 count is in the official agency financial report. These totals are only a structural ceiling of 233 actions before removing individuals, private firms, commodity pools/funds, registered intermediaries that cannot be mapped to listed parents, duplicate/later court-result announcements, and entities outside the frozen issuer sample. They do not repair the missing point-in-time page and attachment history, so no issuer matching or coverage screen was opened.

The frozen external audit manifest SHA-256 is `17d91138e70a54d168f738e2f01e87cdab3545e54aa2c7a85ebb619065a2308a`. It records the official annual-result pages, FY2021 agency financial report, the edited-release counterexample, the 2021 sample release, response headers, URLs, and individual SHA-256 hashes.
